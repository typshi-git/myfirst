# What is Git vs. GitHub?

* **Git:** A distributed version control system that tracks changes in your code locally on your computer.
* **GitHub:** A cloud-based hosting service that lets you manage Git repositories and collaborate with others online.

> **Think of it like this:** Git is the camera; GitHub is the photo album you share with the world.

---

# The Core Workflow

1. **Clone** – Download a repository to your local machine.
2. **Branch** – Create an isolated workspace for a new feature or fix.
3. **Commit** – Save snapshots of your changes with clear messages.
4. **Push** – Upload your local commits to GitHub.
5. **Pull Request (PR)** – Propose your changes and request a code review.
6. **Merge** – Combine your approved changes into the main branch.

# Essential Commands

```bash
# Start a new repository or download an existing one
git init
git clone <repository-url>

# Create and switch to a new branch
git checkout -b feature/new-idea

# Stage and save your changes
git add .
git commit -m "Add new feature"

# Send changes to GitHub
git push origin feature/new-idea
